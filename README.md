# Dietary Acid Load Analysis

**Nutrition science × data analytics | Undergraduate portfolio project**

This project explores dietary acid load using public nutrition and health data, connecting my nutrition science background with data cleaning, statistical analysis, and reproducible research.

## Research questions
- How can nutrient intake data be used to estimate dietary acid load?
- Which dietary components or food categories contribute to these estimates?
- How could dietary acid load be evaluated in relation to serum bicarbonate?
- What reliability and survey-design limitations affect interpretation?

## Data and workflow
The planned data source is NHANES dietary recall, demographic, and relevant laboratory files, with USDA food composition and category references as needed.

1. Review source documentation and identify required variables.
2. Import, clean, and merge records using appropriate participant and recall identifiers.
3. Evaluate missing values, units, and eligible observations.
4. Construct dietary acid load features using a documented formula.
5. Summarize distributions and investigate associations where data support analysis.
6. Report limitations and generate clear visualizations.

## Technical skills
**Python:** dataset preparation, validation and derived variables.  
**SQL:** querying and organizing structured data.  
**R:** statistical modeling and visualizations, including survey-aware methods where appropriate.

## Why it matters
As a Nutrition Science student transitioning toward graduate study in analytics, I wanted to apply analytical methods to a real public-health question. This project emphasizes asking useful questions, evaluating data quality, and communicating results responsibly.
